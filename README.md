# ai-meeting-notes

ai-meeting-notes는 회의 녹취와 메모를 구조화된 회의록으로 바꾸는 서비스입니다.

## 운영 규칙

회의록은 Summary, Decisions, Action Items, Open Questions 순서로 정리합니다.

Action Item에는 담당자와 마감일을 가능한 한 함께 기록합니다.

참석자나 발화자가 불명확한 경우 임의로 이름을 추정하지 않습니다.

결정사항은 의견과 구분해서 Decisions 섹션에만 기록합니다.

요약 품질에 영향을 주는 변경은 샘플 회의록으로 회귀 확인 후 병합합니다.

민감한 고객명, 토큰, 개인 연락처는 회의록에 그대로 노출하지 않습니다.
